# Spec Delta

## ADDED Requirements

### Requirement: The agent corner holds the feedback button for pilot members

For a member with agent access, the feedback button SHALL become the Feedback tab of the agent corner (LAB-3302, S5-R2). The tab SHALL open the same drawer, with the same `feedback-button-click` event and `source` `floating-button`. Alt+F, the (?) menu and the hide preference SHALL work as before. Every other member SHALL keep the feedback button with no change.
